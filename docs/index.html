Qlima Control

Lokal styring af Qlima/Midea-varmepumper med en ESP32-C3 i anlæggets USB-port.

Brug Chrome eller Edge på en computer for at installere. Siden skal åbnes via https.
  1. Sæt ESP32-C3'en i computeren med USB-C og tryk Installér.
  2. Vælg dit WiFi direkte i installeren – eller forbind senere til netværket Qlima Control (kode qlimacontrol).
  3. Byg den ind i anlægget som beskrevet i vejledningen.
  4. Home Assistant finder den selv. Tilføj derefter integrationen Qlima Control.

Web-UI på ESP'en: http://<ip-adresse> · bruger admin · kode qlima
